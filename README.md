# Sổ Tay Cà Phê Việt

Website tiếng Việt gồm trang chủ, ba bài về cà phê và một bài giới thiệu WordPress trong bảng so sánh CMS.

## Website

https://lethanhtu196tt-svg.github.io/

## Chạy thử

Mở `index.html` trong trình duyệt. Các liên kết nội bộ dùng đường dẫn tương đối.

## Cấu trúc

- `index.html`: trang chủ.
- `huong-dan/`, `hat-ca-phe/`, `cam-nang/`: ba bài hướng dẫn cà phê.
- `cong-cu/cms-wordpress.html`: bài giới thiệu WordPress trong bảng so sánh.
- `assets/`: CSS, ảnh Unsplash có ghi nguồn và biểu trưng WordPress tải từ trang chính thức; xem trang CMS để biết lưu ý thương hiệu.
- `robots.txt`, `sitemap.xml`: SEO kỹ thuật với URL công khai.

## CMS/hosting

Bài thực hành chọn Publii + GitHub Pages. Bản triển khai hiện là website HTML/CSS tĩnh; nội dung chưa được nhập hoặc đồng bộ từ ứng dụng Publii. Website này không chạy trên WordPress; logo WordPress chỉ minh họa phương án CMS được so sánh.
